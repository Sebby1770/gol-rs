# Changelog

## 1.0.0 - 2026-07-17

- Split the simulation into a reusable, documented Rust library.
- Added configurable Life-like rules and finite/toroidal boundaries.
- Added strict RLE import, stdin support, and final-state RLE export.
- Expanded the pattern catalogue to ten well-known seeds.
- Added transition statistics, JSON Lines output, and deterministic headless runs.
- Added bit-packed exact-state stability and oscillator detection with state and
  memory budgets.
- Added checked allocation/placement limits, comprehensive tests, CI, and
  package validation.

## 0.1.0 - 2026-05-06

- Initial dependency-free terminal implementation with four patterns.
